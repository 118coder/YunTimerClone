# 定时关机助手

**一款免费、绿色的 Windows 定时关机小工具**：到点自动帮你关机、重启、注销、休眠或锁定电脑。
不用安装，下载一个 exe 双击就能用；启动不到 0.2 秒；整个程序只有一个 70KB 的文件。

> 灵感来自经典软件「YunTimer 定时关机助手」v2.0.1.9，界面与交互按原版复刻，代码全部原创。

## 📥 下载（三步搞定）

1. 打开 [**Releases 发行页**](https://github.com/118coder/YunTimerClone/releases)，下载 `定时关机助手.exe`
2. 双击运行 —— **不需要安装**，Windows 10 / 11 开箱即用
3. 选时间 → 选动作 → 点「执 行」，完成！

## 🕐 怎么用

1. 顶部选定时方式：**指定时间**（比如 23:30 关机）或 **倒计时**（比如 1 小时 30 分后关机）
2. 点击时间框里的「小时」或「分钟」，**直接敲数字**；也可以拖下面的滑块
3. 选择到点后做什么：关机 / 重启 / 注销 / 休眠 / 锁定
4. 点「**执 行**」

到点前 **60 秒**会弹出提醒窗口倒数，这时你可以：立即执行、**延迟 10 分钟**、或者直接取消——不怕误关机。

## ✨ 它能做什么

- ⏰ 指定时间 / 倒计时两种定时方式
- 🔌 关机、重启、注销、休眠、锁定五种动作
- 🔔 执行前弹窗倒数提醒，可取消、可延迟
- 🚀 原生程序，双击秒开（实测 60~200 毫秒）
- 📌 最小化到托盘，右键托盘图标随时管理
- 💻 可选「开机自启动」，设置一次天天能用
- 🧪 「模拟模式」先体验不真关机（见下面常见问题）

## ❓ 常见问题

**会不会误关机？**
不会。到点前 60 秒弹出提醒，可以取消或延迟；主界面随时可以点「取消定时」。

**杀毒软件提示有风险？**
本工具是免费小工具，没有购买代码签名，属于正常提示，选择「仍要运行」即可。不放心的可以先用模拟模式：按住 exe 拖到命令行输入 `--simulate` 参数运行（或 `selftest.exe --selftest` 查看自检结果），所有动作只记录不执行。

**想每天 23:30 自动关机？**
用「指定时间」设好并执行即可；目前到点执行一次后需要再设（每日自动重复在计划中）。

**怎么取消已经定好的任务？**
主界面点「取消定时」，或关机提醒弹窗里点「取 消」。

**如何卸载？**
直接删除 exe 文件即可；如果开了「开机自启动」，先在界面里关闭该开关。

**技术形态**：纯 Win32 API + GDI 自绘的原生 C 程序（单文件 `src/yuntimer.c`），无运行时、无 JIT，gcc (mingw-w64) 编译，约 70KB。

**构建**：运行 `build.cmd`（自动调用 gcc + windres 编译图标/版本资源），产物在 `dist/`。

**测试**（全部为模拟执行，绝不真实关机）：
- `selftest.exe --selftest`：27 项逻辑自检（定时引擎、跨午夜、延迟/取消、配置读写等）
- `selftest.exe --uitest`：窗口创建冒烟测试（不显示窗口）
- 启动性能：双击到窗口出现实测 62~156ms

**功能对照原版**：紧凑时间头（日期左/时间右）、指定时间与倒计时页签、`HH : MM` 大号时间盒（真 EDIT 控件，失焦补零校验）、单滑块控制焦点段、执行前弹窗（执行/延迟 10 分钟/取消）、30 秒后强制关机兜底、托盘气泡与右键菜单、开机自启动注册表、config.ini 记忆设置、原版趣味文案。

**实现注记**：定时引擎在设定任务时即固定触发时刻，修复了"每次重算下次触发导致固定时间任务永不触发"的缺陷（回归项 `engine.fixedFiresOnce`）。图标由 `tools/make_icon.py`（纯标准库）生成多尺寸 ico，经 windres 嵌入 exe。

**与原版的关系**：功能与交互向 YunTimer（定时关机助手）v2.0.1.9 致敬；代码为本仓库作者原创实现；与 www.yunguanji.com 官方无关，非官方产品。
