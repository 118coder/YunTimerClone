# 定时关机助手（YunTimer 复刻版 · 原生 C）

一个 Windows 桌面「定时关机助手」，功能与交互复刻自 [www.yunguanji.com](https://www.yunguanji.com) 的 **YunTimer v2.0.1.9「定时关机助手」**，界面为手写 Fluent 深色设计。代码为 100% 原创实现（未复制、未反编译原程序的任何代码与资源）。

**与原版相同的技术形态：纯 Win32 API + GDI 自绘的原生 C 程序**——无常驻运行时、无 JIT、无框架加载，单 exe 约 40KB、零依赖，**双击 60~150ms 窗口即现**（实测数据见下）。

> 为什么秒开？原版 YunTimer 是 2012 年的原生 C++ 程序，点击后直接执行机器码。本项目的 WPF/.NET 版本曾做到 55KB，但托管运行时+框架初始化有约 1~3 秒的地板成本，无法达到原版手感，故最终回归原生 C。

## 实测启动性能

| 版本 | 体积 | 双击到窗口出现 |
|---|---|---|
| 原版 YunTimer v2.0.1.9 | ~1MB | 瞬间 |
| ~~WPF/.NET 版（已移除，见 git 历史）~~ | 55KB~6.8MB | 0.7~3.2s |
| **原生 C 版（当前）** | **40KB** | **62ms（热）/ 156ms（冷）** |

## 功能（对照原版）

- 当前时间大时钟 + 日期显示
- 两种定时模式：**固定时间定时 / 倒计时定时**（小时、分钟支持数字框 + 滑块双向调节）
- 执行动作：**关机 / 重启 / 注销 / 休眠 / 锁定**（芯片式选择器）
- 定时到达前弹窗提醒「关机提醒：请注意保存文件！系统将在 N 秒后关闭」，圆环倒计时结束自动执行
- 弹窗三选项：**执 行 / 延迟 10 分钟 / 取 消**
- 关机命令未生效时，等待 30 秒后自动转**强制关机**（复刻原版逻辑）
- 托盘图标（运行时 GDI 绘制）：最小化到托盘、气泡提示、右键菜单管理
- **开机自启动**（写入 HKCU `Software\Microsoft\Windows\CurrentVersion\Run`）
- `config.ini` 记忆上次的设置（exe 目录不可写时自动回落到 %APPDATA%）
- Windows 11 深色标题栏 + 原生圆角窗口（DWM）
- 保留原版趣味文案：「亲，这个是火星文嘛？看不懂啊」

## 使用

直接双击 `dist\定时关机助手.exe`，无需安装任何东西。

| 启动方式 | 说明 |
|---|---|
| `定时关机助手.exe` | 正常模式，定时到达后真实执行 |
| `定时关机助手.exe --simulate` | **模拟模式**：所有动作只写入 `simulate.log`，绝不真正关机（安全预览用） |
| `selftest.exe --selftest` | 逻辑自检（27 项断言，无界面，无任何系统副作用） |
| `selftest.exe --uitest` | 窗口创建冒烟测试（不显示窗口） |

## 构建

需要 [mingw-w64](https://www.mingw-w64.org/) 的 gcc（本机已装于 `C:\mingw64`）：

```
build.cmd
  → dist\定时关机助手.exe   主程序（原生 C，约 40KB，零依赖）
  → dist\selftest.exe       逻辑/UI 自检运行器
```

单源文件 `src\yuntimer.c`：核心逻辑（定时引擎/校验/执行器/INI 配置）与 GDI 自绘 Fluent 界面同文件组织。

> 实现注记：定时引擎在设定任务时即固定触发时刻（fireAt），修复了"每次重算下次触发导致固定时间任务永不触发"的缺陷，并有专门的回归自检项 `engine.fixedFiresOnce`。
